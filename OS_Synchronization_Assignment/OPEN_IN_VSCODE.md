# Open and run in VS Code

1. Extract this ZIP.
2. In VS Code select File > Open Folder and choose OS_Synchronization_Assignment.
3. Install Python 3.10 or later and the Microsoft Python extension if needed.
4. Open Terminal > New Terminal. Run each command separately:

```bash
python readers_writers/semaphore_solution.py
python readers_writers/monitor_solution.py
python dining_philosophers/semaphore_solution.py
python dining_philosophers/monitor_solution.py
```

On Windows, use `py` instead of `python` if necessary.
No pip packages are required. Each program produces its HTML replay in generated_html.
Open the HTML file in your browser. The Python programs must run first to generate fresh execution events.
